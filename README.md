# Zaman Yolcusu Oturum Açma Sistemi

## Bu Ne?

Bu, insanlığın en büyük başarısıdır. Zaman yolculuğu artık bir tık uzağınızda. Ya da değildir. Ama denedik.

Bu repository, zamanın dokusunu yırtmak yerine sadece size "başarısız oldun" diyen mükemmel bir oturum açma sistemidir. Bilim insanları şaşkın, fizikçiler çaresiz, biz ise çok ciddiyiz.

## Özellikler

- **Gerçekten çalışır**: Python ile yazıldı, terminalde koşar, hayatınızı değiştirmez.
- **Sonsuz hata mesajları**: Her seferinde farklı bir saçmalık.
- **Zaman yolculuğu başarısız**: Bu bir özellik. Başarısız olmak da bir başarıdır.
- **Gizli mesaj**: Kodun içinde saklı. Bulursanız ödül yok ama övünürsünüz.
- **Türkçe**: Çünkü zaman bile Türkçe konuşur bazen.

## Kurulum

```bash
git clone https://github.com/Tentivory/zaman-yolcusu-oturum-acma.git
cd zaman-yolcusu-oturum-acma
python zaman_yolcusu.py
```

Python 3 yüklü olsun yeter. Yoksa zaman yolculuğu için değil, çay demlemek için bile uygun değilsiniz.

## Kullanım

Scripti çalıştırın, yıl girin, izleyin nasıl başarısız oluyorsunuz. Her seferinde farklı bir bahane. Mükemmel.
